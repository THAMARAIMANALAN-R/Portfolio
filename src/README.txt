THAMARAI MANALAN PORTFOLIO

FILES
- index.html
- css/style.css
- js/script.js
- assets/images/profile.jpg (add your portrait here)
- assets/documents/resume.pdf (add your resume here)

CUSTOMIZE BEFORE PUBLISHING
1. Replace YOUR_EMAIL@example.com in index.html and js/script.js.
2. Replace GitHub, LinkedIn and LeetCode placeholder profile URLs.
3. Replace project href="#" links with real project/demo/repository URLs.
4. Add your photograph as assets/images/profile.jpg.
5. Add your resume as assets/documents/resume.pdf.

RUN
Open index.html in a browser. For local development, you can also use VS Code Live Server.

The contact form currently opens the visitor's default email application (mailto). It does not send messages through a backend.
